# My Study Space

A view-only mirror of a personal grade-12 study site — summaries, learning objectives, key terms, quizzes, and flashcards, in English and Arabic.

Open the live site: see the repository's **About** section on GitHub, or ask whoever shared this link with you.

This repository only ever contains the public [`docs/`](docs) folder that GitHub Pages serves. The original course files (PowerPoints, PDFs, worksheets) and the private authoring tools that built this site are never published here.

Progress and quiz scores are saved in each visitor's own browser (`localStorage`) — nothing is sent anywhere or shared between visitors.
